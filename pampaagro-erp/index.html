    Términos y Condiciones de Uso del Trial - Nexo Agro

    1. Objeto

    El presente documento regula el acceso y uso del período de prueba gratuito ("Trial") de 7 días del software Nexo Agro - Sistema de Gestión.

    2. Condiciones del Trial

    El Trial otorga acceso temporal, no exclusivo e intransferible a los módulos agrícolas, ganaderos, financieros y de maquinaria de la plataforma por un plazo estricto de 7 (siete) días corridos a partir de la fecha de registro. El uso está limitado a la evaluación interna del sistema por parte del productor o empresa solicitante.

    3. Arquitectura Offline y Datos

    Nexo Agro es un sistema offline-first. La carga de datos se realiza de forma local en el dispositivo del usuario. Nexo Agro no se responsabiliza por la pérdida de datos cargados durante el período de prueba si el usuario desinstala la aplicación o si el Trial expira sin realizar la migración a una licencia perpetua.

    4. Modelo de Licenciamiento

    Al finalizar los 7 días, el acceso al sistema se suspenderá automáticamente. Para mantener los registros y continuar utilizando las funciones, el usuario deberá adquirir una licencia definitiva mediante los canales de pago autorizados:

    • • Transferencia Bancaria
    • • Tarjeta Agropecuaria
    • • Canje de Granos

    Nexo Agro se compromete a otorgar mejoras sobre los módulos adquiridos bajo la modalidad de pago único, sujeto a las condiciones de soporte técnico vigentes.
